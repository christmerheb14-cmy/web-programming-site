Introduction

The Web is a service that runs on the Internet. In its technically most accurate use, the term “Web” refers to the World Wide Web. The Internet is the worldwide connection of computers; the Web is the software, usually a web browser, that lets people navigate, view, and interact with multimedia documents.

The main technologies that the Web runs on are URLs (Uniform Resource Locators), HTML (HyperText Markup Language), and HTTP (Hypertext Transfer Protocol). URLs are web addresses that uniquely specify a resource. HTML specifies the formatting of text, images, and other embedded media into documents that can be displayed as web pages. HTTP determines how browsers and servers request and transmit files over the Internet.

Clickable hyperlinks embedded in documents convert the connectivity of networks into a human-readable and interconnected web of digital information. The history of the Web is therefore separate from the history of the Internet, which provides the worldwide network on which the Web operates.

History of the Web

1989 — The World Wide Web Was Proposed

Event: Tim Berners-Lee proposed the World Wide Web while working at CERN.

Explanation: The proposal introduced the idea of linking information across different computers into a global information system.

Why it mattered: It provided the concept that became the World Wide Web.

Source: CERN

1990 — The First Web Browser, Server, and Website Were Created

Event: The first Web browser/editor, Web server, and website were created at CERN.

Explanation: This turned the Web from a proposal into a working system. The first website was hosted at info.cern.ch.

Why it mattered: A working browser, server, and website made the proposed system operational.

Source: CERN

1991 — The Web Was Announced Publicly

Event: The Web was announced publicly on the Internet.

Explanation: The announcement made information about the Web available beyond CERN.

Why it mattered: Researchers outside CERN could begin accessing the Web and contributing to its development.

Source: W3C

1991 — The First Web Server Outside Europe Was Established

Event: The first Web server outside Europe was established at SLAC in the United States.

Explanation: The Web began expanding from CERN to a location in the United States.

Why it mattered: The Web began spreading beyond CERN and the European physics community.

Source: CERN

1993 — The Mosaic Web Browser Was Released

Event: The Mosaic Web browser was released by the National Center for Supercomputing Applications.

Explanation: Mosaic provided a graphical, user-friendly interface for using the Web.

Why it mattered: Mosaic made the Web accessible to a much broader audience, including home and office users.

Source: CERN

1993 — CERN Made the Web Software Royalty-Free

Event: CERN made the Web software available royalty-free and effectively placed the Web in the public domain.

Explanation: The software could be used without licensing barriers.

Why it mattered: This encouraged widespread adoption, development, and innovation.

Source: CERN

1994 — The First International World Wide Web Conference Was Held

Event: The first International World Wide Web Conference was held at CERN.

Explanation: The conference brought Web developers and users together.

Why it mattered: It helped establish an international Web community.

Source: CERN

1994 — The World Wide Web Consortium Was Founded

Event: Tim Berners-Lee founded the World Wide Web Consortium, or W3C.

Explanation: The W3C was created to coordinate open technical standards.

Why it mattered: Open technical standards helped websites and browsers work together.

Source: W3C / CERN

1994 — The Web Experienced Rapid Global Growth

Event: The Web experienced rapid global growth, reaching approximately 10,000 servers and 10 million users by the end of the year.

Explanation: The number of Web servers and users increased substantially during the year.

Why it mattered: This showed that the Web had moved beyond a research project and was becoming a widely used public platform.

Source: CERN

1995 — Commercial Use of the Web Expanded

Event: Commercial use of the Web expanded significantly.

Explanation: Businesses, Internet service providers, and online services became increasingly involved in Web use.

Why it mattered: Commercial activity helped transform the Web into a major platform for commerce, publishing, and communication.

Source: Internet Society

Key Web Technologies

HTML

HTML, or HyperText Markup Language, defines the structure and content of Web pages.

CSS

CSS, or Cascading Style Sheets, controls the appearance and layout of Web pages, including colors, fonts, and responsive design.

JavaScript

JavaScript adds interactivity and dynamic behavior to Web pages, such as menus, animations, forms, and real-time updates.

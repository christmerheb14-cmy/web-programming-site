Introduction

The Web is a service that runs on the Internet. In its technically most accurate use, the term “Web” is used to refer to the World Wide Web. The Internet is the worldwide connection of computers; the Web is the software usually a web browser that lets one navigate, view, and interact with multimedia documents. The main technology that the Web runs on are the URLs (Unform Resource Locators), HTML (HyperText Markup Language), and HTTP (Hypertext Transfer Protocol). URLs are the web addresses that uniquely specify a resource. HTML specifies the formatting of text, images, and other embedded media, into documents that can be respawned into web pages. HTTP then determines the way browsers and servers request and transmit the files over the Internet. There are clickable hyperlinks embedded in documents and by this feature, the Web converts mere connectivity of networks into a human-readable and interconnected web of digital information.

Web History Timeline

1989 — Tim Berners-Lee proposed the World Wide Web while working at CERN.

The proposal introduced the idea of linking information across different computers into a global information system.

Source: CERN

1990 —The first Web browser/editor, Web server, and website were created at CERN.

This turned the Web from a proposal into a working system. The first website was hosted at info.cern.ch.

Source: CERN

1991 —The Web was announced publicly on the Internet.

Researchers outside CERN could begin accessing the Web and contributing to its development.

Source: W3C

1991 —The first Web server outside Europe was established at SLAC in the United States.

The Web began spreading beyond CERN and the European physics community.

Source: CERN

1993 —The Mosaic Web browser was released by the National Center for Supercomputing Applications.

Mosaic’s graphical, user-friendly interface made the Web accessible to a much broader audience, including home and office users.

Source: CERN

1993 —CERN made the Web software available royalty-free and effectively placed the Web in the public domain.

This removed licensing barriers and encouraged widespread adoption, development, and innovation.

Source: CERN

1994 —The first International World Wide Web Conference was held at CERN.

It brought Web developers and users together and helped establish an international Web community.

Source: CERN

1994 —Tim Berners-Lee founded the World Wide Web Consortium, or W3C.

The W3C was created to coordinate open technical standards so that websites and browsers could work together.

Source: W3C / CERN

1994 —The Web experienced rapid global growth, reaching approximately 10,000 servers and 10 million users by the end of the year.

This showed that the Web had moved beyond a research project and was becoming a widely used public platform.

Source: CERN

1995 —Commercial use of the Web expanded significantly.

Businesses, Internet service providers, and online services helped transform the Web into a major platform for commerce, publishing, and communication.

Source: Internet Society

Key Technologies

HTML (HyperText Markup Language)

Defines the structure and content of Web pages.

CSS (Cascading Style Sheets)

Controls the appearance and layout of Web pages, including colors, fonts, and responsive design.

JavaScript

Adds interactivity and dynamic behavior to Web pages, such as menus, animations, forms, and real-time updates.
